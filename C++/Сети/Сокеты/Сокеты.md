	# Сокеты

**Сокет** — это абстракция для обмена данными между процессами по сети или внутри одной машины. Сокеты используются для реализации сетевого взаимодействия на уровне приложений.

---

## Основная идея
- Сокет — это конечная точка соединения между двумя машинами (или процессами).
- Сокеты предоставляют универсальный интерфейс для передачи данных независимо от протокола (TCP, UDP и др.).

## Виды сокетов
1. **Stream-сокеты (SOCK_STREAM)**
   - Основаны на протоколе TCP.
   - Обеспечивают надёжную, ориентированную на соединение передачу данных (поток байтов).
   - Гарантируют доставку, порядок и отсутствие дубликатов.
2. **Datagram-сокеты (SOCK_DGRAM)**
   - Основаны на протоколе UDP.
   - Передают отдельные сообщения (датаграммы), не гарантируют доставку и порядок.
   - Быстрее, но менее надёжны.
3. **Raw-сокеты (SOCK_RAW)**
   - Дают доступ к "сырым" IP-пакетам.
   - Используются для реализации собственных протоколов, утилит анализа трафика, ping, traceroute и др.
4. **Sequenced packet sockets (SOCK_SEQPACKET)**
   - Ориентированы на передачу сообщений с сохранением порядка и границ сообщений.
   - Используются редко, специфичны для некоторых протоколов (например, SCTP).
5. **Unix domain sockets (AF_UNIX, AF_LOCAL)**
   - Для обмена данными между процессами на одной машине.
   - Быстрее, чем сетевые сокеты, не используют сетевой стек.

## Основные функции работы с сокетами (на примере POSIX)
- `socket()` — создание сокета
- `bind()` — привязка к адресу
- `listen()` — перевод в режим ожидания соединений (только для TCP)
- `accept()` — принятие входящего соединения
- `connect()` — установка соединения с удалённым сокетом
- `send()`, `recv()` — отправка и приём данных
- `close()` — закрытие сокета

## Пример создания TCP-сервера (POSIX)
```cpp
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>

int server_fd = socket(AF_INET, SOCK_STREAM, 0);
sockaddr_in addr{};
addr.sin_family = AF_INET;
addr.sin_addr.s_addr = INADDR_ANY;
addr.sin_port = htons(8080);
bind(server_fd, (sockaddr*)&addr, sizeof(addr));
listen(server_fd, 5);
int client_fd = accept(server_fd, nullptr, nullptr);
// ... работа с client_fd ...
close(client_fd);
close(server_fd);
```

## Особенности
- Сокеты бывают блокирующими и неблокирующими.
- Для работы с несколькими соединениями используют select, poll, epoll, io_uring и др [[Асинхронные сокеты]].
- В Windows API для работы с сокетами используется Winsock (функции WSA*).

## Важно
- Для сетевого взаимодействия важно учитывать вопросы безопасности (валидация данных, защита от атак).
- Сокеты — фундаментальный инструмент для реализации сетевых протоколов, клиент-серверных приложений, межпроцессного взаимодействия.
