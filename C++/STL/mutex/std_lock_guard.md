- Легковесная обёртка RAII для автоматического управления временем жизни блокировки.
- Не поддерживает явную разблокировку или повторное захватывание (lock/unlock вручную невозможны).
- Используется для простых случаев, когда требуется заблокировать мьютекс на время области видимости.

**Пример:**
```cpp
std::mutex m;
void f() {
    std::lock_guard<std::mutex> lock(m);
    // критическая секция
} // m автоматически разблокируется
```

**В отличие от std::unique_lock:**
- Меньше по размеру и быстрее
- Нет поддержки отложенной блокировки, повторного захвата, передачи блокировки
