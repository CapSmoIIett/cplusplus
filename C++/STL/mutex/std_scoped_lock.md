# std::scoped_lock

`std::scoped_lock` — это обёртка RAII для автоматического управления временем жизни одной или нескольких блокировок (mutex), появившаяся в [[C++17]].

## Основные особенности
- Позволяет захватывать сразу несколько мьютексов, предотвращая взаимные блокировки ([[deadlock]]) с помощью алгоритма lock-all-at-once.
- Захватывает мьютексы в конструкторе и освобождает их в деструкторе (RAII).
- Не поддерживает явную разблокировку или повторное захватывание.
- Не копируемый и не перемещаемый.
- Быстрее и проще, чем `std::lock_guard`, если нужно захватить несколько мьютексов.

## Пример использования
```cpp
#include <mutex>

std::mutex m1, m2;

void f() {
    std::scoped_lock lock(m1, m2); // оба мьютекса захвачены атомарно
    // критическая секция
} // оба мьютекса автоматически освобождаются
```

## Отличие от других обёрток
- В отличие от `std::lock_guard`, может принимать несколько мьютексов.
- В отличие от `std::unique_lock`, не поддерживает отложенную блокировку, передачу владения и явное unlock().
- Использует алгоритм [[deadlock avoidance]] (lock all at once).

## Когда использовать
- Когда нужно безопасно захватить несколько мьютексов одновременно.
- Для простых случаев, когда не требуется гибкость `unique_lock`.

## Важно
- Порядок передачи мьютексов в конструктор не влияет на безопасность (deadlock avoidance реализован внутри).
- Не используйте с рекурсивными мьютексами, если один и тот же мьютекс передаётся несколько раз.
