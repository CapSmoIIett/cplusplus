
#### **Встроенные средства C++ (Windows CRT)**  

Включите отладку кучи через заголовки `<crtdbg.h>` и макросы:

```C++
#define _CRTDBG_MAP_ALLOC
#include <cstdlib>
#include <crtdbg.h>
#ifdef _DEBUG
    #define new new(_NORMAL_BLOCK, __FILE__, __LINE__)
#endif
```

Для вывода утечек в консоль используйте `_CrtDumpMemoryLeaks()` или `_CrtMemDumpAllObjectsSince()`.

[источник](https://habr.com/ru/articles/82514/)

#### **Valgrind (Linux/macOS)**  
Инструмент `memcheck` обнаруживает утечки, неверные обращения к памяти.

#### **Google Performance Tools (gperftools)**  
Библиотека `tcmalloc` отслеживает выделения памяти
