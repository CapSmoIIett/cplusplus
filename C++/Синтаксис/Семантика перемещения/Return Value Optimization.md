# Return Value Optimization (RVO) в C++

**Return Value Optimization (RVO)** — это техника оптимизации компилятора, позволяющая избежать лишнего копирования или перемещения объектов при возврате значения из функции.

---

## Основная идея
- При возврате объекта из функции компилятор может создать объект сразу в памяти, предназначенной для результата, минуя временные объекты и вызовы конструктора копирования/перемещения.
- Это существенно повышает производительность, особенно для тяжёлых объектов.

## Виды оптимизации
- **RVO (Return Value Optimization):** Оптимизация для временных объектов, возвращаемых непосредственно из функции.
- **NRVO (Named Return Value Optimization):** Оптимизация для именованных локальных переменных, возвращаемых из функции.

## Пример RVO
```cpp
struct Data {
    Data() { /* ... */ }
    Data(const Data&) { /* ... */ }
    Data(Data&&) { /* ... */ }
};

Data make_data() {
    return Data(); // RVO: объект создаётся сразу в месте назначения
}
```

## Пример NRVO
```cpp
Data make_data() {
    Data d;
    // ...
    return d; // NRVO: d создаётся сразу в месте назначения
}
```

## Взаимодействие с move-семантикой
- Если RVO/NRVO невозможна, компилятор использует move-конструктор (если он есть).
- В современных компиляторах (C++17 и выше) RVO обязателен в большинстве случаев (guaranteed copy elision).

## Стандарты и поддержка
- RVO разрешён начиная с C++98, но не гарантирован.
- С C++17 copy elision (RVO) обязателен для случаев возврата временного объекта (return T(...);).

## Ограничения
- NRVO не гарантирован даже в C++17 (зависит от компилятора).
- RVO невозможен, если возвращается разный объект в зависимости от условий (например, return d1; return d2;).
- RVO не применяется, если возвращается ссылка.

## Важно
- RVO/NRVO — ключевой механизм для эффективной работы с временными объектами и современными контейнерами.
- Не стоит явно вызывать std::move при возврате локального объекта — это может помешать RVO.
- Использование RVO делает код чище и эффективнее без дополнительных усилий со стороны программиста.
