auto представляет собой [[Вывод типов]] шаблона.

В объявлении переменной с использованием auto спецификатор типа занимает место ParamType.

Они отличаются только в одном:

[[initializer_list]]

```c++
auto x1 = 27; // Тип int , значение - 27 
auto х2 (27); // То же самое 
auto хЗ = {27}; // std::initializer_list<int>, значение {27} 
auto х4 {27}; // То же самое
```


Таким образом, единственное реальное различие между выводом типа auto и выводом типа шаблона заключается в том, что auto предполагает, что инициализатор в фигурных скобках представляет собой std : : ini t i a l i zer_l i st, в то время как вывод типа шаблона этого не делает.
