# Syntax

**SFINAE** (Substitution Failure Is Not An Error) — это фундаментальное правило в языке C++, которое позволяет избежать ошибок компиляции при неудачной подстановке шаблонных параметров. Оно тесно связано с шаблонами и перегрузкой функций.

#### Основная идея SFINAE

Когда компилятор пытается подставить шаблонные параметры в функцию, он не выбрасывает ошибку, если подстановка не удалась. Вместо этого, он просто исключает эту функцию из списка кандидатов на вызов и продолжает поиск другой подходящей перегрузки. Ошибка возникает только в трех случаях:

1. **Нет подходящих перегрузок**: Если не найдено ни одной подходящей функции.
2. **Несколько подходящих перегрузок**: Если найдено несколько подходящих функций, но компилятор не может решить, какую из них выбрать.
3. **Ошибка при инстанцировании шаблона**: Если функция является шаблонной и при ее инстанцировании возникает ошибка.

---

## Как работает SFINAE
- Применяется только к шаблонным функциям и классам.
- Если при подстановке параметров шаблона возникает ошибка (например, тип не поддерживает нужную операцию), компилятор не завершает компиляцию с ошибкой, а просто исключает этот шаблон из рассмотрения.
- Позволяет реализовывать перегрузку функций и специализации на основе свойств типов.

## Пример SFINAE с enable_if
```cpp
#include <type_traits>

// Функция только для целых типов
template<typename T>
std::enable_if_t<std::is_integral_v<T>, void> foo(T) {
    // ...
}

// Функция только для вещественных типов
template<typename T>
std::enable_if_t<std::is_floating_point_v<T>, void> foo(T) {
    // ...
}
```

## Пример SFINAE через параметры шаблона
```cpp
template<typename T>
auto bar(T t) -> decltype(t.begin(), void()) {
    // Эта версия выберется, если у T есть метод begin()
}

template<typename T>
void bar(...) {
    // Эта версия выберется, если у T нет метода begin()
}
```

## Способы применения SFINAE
- Ограничение доступности функций для определённых типов (type traits + enable_if).
- Детектирование наличия членов класса, методов, операторов (detection idiom).
- Реализация "фолбэков" (fallback) для типов, не удовлетворяющих условиям.

## Ограничения и замечания
- SFINAE работает только на этапе выбора перегрузки, а не при непосредственной инстанцировании шаблона.
- В современных версиях C++ ([[C++17]] и выше) многие задачи SFINAE проще решать с помощью if constexpr и detection idiom.
- Код с SFINAE может быть сложен для понимания и отладки.

## Важно
- SFINAE — мощный инструмент метапрограммирования, лежащий в основе многих библиотек (например, STL, Boost).
- Позволяет писать обобщённый и безопасный код, который автоматически адаптируется под свойства типов.
