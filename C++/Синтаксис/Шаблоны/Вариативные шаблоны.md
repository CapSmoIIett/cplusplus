# Вариативные шаблоны в C++

**Вариативные шаблоны (variadic templates)** — это шаблоны, которые могут принимать произвольное количество параметров типов или значений. Введены в [[C++11]].

---

## Синтаксис
- Используется специальный синтаксис с многоточием (`...`):
```cpp
template<typename... Args>
void func(Args... args);
```
- `Args...` — пакет параметров шаблона (template parameter pack)
- `args...` — пакет аргументов функции (function parameter pack)

## Рекурсивная обработка аргументов
- Классический способ обработки пакета аргументов — рекурсивное развертывание:
```cpp
template<typename T>
void print(const T& t) {
    std::cout << t << std::endl;
}

template<typename T, typename... Args>
void print(const T& t, const Args&... args) {
    std::cout << t << ", ";
    print(args...); // рекурсивный вызов
}
```

## Fold expressions (C++17)
- Позволяют компактно "свернуть" пакет аргументов с помощью оператора:
```cpp
template<typename... Args>
void print_all(const Args&... args) {
    ((std::cout << args << " "), ...);
}
```
- Пример суммы всех аргументов:
```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ...); // (a1 + (a2 + (a3 + ...)))
}
```

## Использование с std::tuple
- `std::tuple` — контейнер для хранения набора значений разных типов.
- Для работы с tuple часто используют вариативные шаблоны и std::apply:
```cpp
#include <tuple>
#include <iostream>
#include <utility>

auto t = std::make_tuple(1, 2.5, "hello");

std::apply([](auto&&... args) {
    ((std::cout << args << " "), ...);
}, t);
```

## Использование с std::function
- Вариативные шаблоны позволяют создавать обобщённые обёртки для функций с любым количеством и типами аргументов:
```cpp
#include <functional>

template<typename R, typename... Args>
std::function<R(Args...)> make_func(R(*f)(Args...)) {
    return std::function<R(Args...)>(f);
}
```

## Использование с std::make_unique
- Вариативные шаблоны позволяют передавать любые аргументы конструктору объекта:
```cpp
#include <memory>

template<typename T, typename... Args>
auto my_make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
// std::make_unique реализован аналогично
```

## Преимущества вариативных шаблонов
- Позволяют писать обобщённые функции и классы для произвольного числа аргументов.
- Упрощают реализацию контейнеров, обёрток, фабрик и других паттернов.
- Повышают выразительность и гибкость кода.

## Важно
- Рекурсивная обработка аргументов может быть менее эффективной и сложной для понимания, чем fold expressions.
- Fold expressions — современный и лаконичный способ работы с пакетами аргументов (начиная с C++17).
- Вариативные шаблоны широко используются в стандартной библиотеке (std::tuple, std::function, std::make_unique и др.).
