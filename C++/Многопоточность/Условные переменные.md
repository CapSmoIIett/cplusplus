# std::condition_variable

`std::condition_variable` — примитив синхронизации для организации ожидания событий между потоками.

## Основные особенности
- Позволяет одному или нескольким потокам ждать наступления определённого условия.
- Для ожидания требуется уникальная блокировка (`std::unique_lock<std::mutex>`).
- Потоки пробуждаются с помощью методов `notify_one()` (один поток) или `notify_all()` (все ждущие потоки).
- Используется совместно с флагом/условием (обычно переменной), чтобы избежать ложных пробуждений (spurious wakeups).

## Пример использования
```cpp
#include <condition_variable>
#include <mutex>
#include <thread>

std::mutex mtx;
std::condition_variable cv;
bool ready = false;

void worker() {
    std::unique_lock lock(mtx);
    cv.wait(lock, []{ return ready; }); // Ждём, пока ready == true
    // ... работа после сигнала ...
}

void notifier() {
    {
        std::lock_guard lock(mtx);
        ready = true;
    }
    cv.notify_one(); // или notify_all()
}
```

## Когда использовать
- Для реализации очередей задач, producer-consumer, синхронизации старта/завершения работы потоков.

## Важно
- После пробуждения всегда проверяйте условие в цикле или через лямбду (из-за возможных ложных пробуждений).
