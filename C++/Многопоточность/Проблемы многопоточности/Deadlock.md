# Multithreading

**Deadlock** – ситуация, при которой несколько потоков находятся в состоянии ожидания ресурсов, занятых друг другом, и ни один из них не может продолжать выполнение.

## Условия возникновения deadlock (по Коффману)
1. **Взаимное исключение (Mutual Exclusion):** Ресурсы не могут быть использованы более чем одним потоком одновременно.
2. **Удержание и ожидание (Hold and Wait):** Поток, уже владеющий одним ресурсом, ожидает другой.
3. **Отсутствие принудительного освобождения (No Preemption):** Ресурсы не могут быть отобраны, их можно только освободить добровольно.
4. **Циклическое ожидание (Circular Wait):** Существует цикл, в котором каждый поток ждёт ресурс, занятый следующим потоком в цикле.

## Пример deadlock
```c++
void fun1() // функция выполняющаяся в одном потоке
{
    mtx1.lock();    // блокировка мьютекса 
    mtx2.lock();    // блокировка мьютекса 
    // ...
    mtx2.unlock();
    mtx1.unlock();
}

void fun2() // функция выполняющаяся в другом потоке 
{
    mtx2.lock();    // блокировка мьютекса 
    mtx1.lock();    // блокировка мьютекса 
    // ...
    mtx1.unlock();
    mtx2.unlock();
}
```

## Как избежать deadlock
- **Всегда захватывать мьютексы в одном и том же порядке во всех потоках.**
- Использовать `std::scoped_lock` или `std::lock`, которые захватывают несколько мьютексов атомарно и предотвращают deadlock.
- Минимизировать время удержания блокировок.
- Избегать вложенных блокировок, если это возможно.
- Использовать таймауты при захвате мьютексов (`try_lock`, `try_lock_for`).

## Обнаружение deadlock
- Вручную: анализ кода, логирование, статический анализ.
- Инструменты: ThreadSanitizer, Helgrind, инструменты профилирования потоков.

## Типичные сценарии возникновения
- Вложенные блокировки нескольких мьютексов в разном порядке.
- Использование нескольких ресурсов без строгого порядка захвата.
- Взаимные вызовы между потоками с блокировками.

## Важно
- Deadlock сложно отлаживать: часто проявляется не всегда, а только при определённом стечении обстоятельств.
- Предотвращение deadlock — важная часть проектирования многопоточных программ.
