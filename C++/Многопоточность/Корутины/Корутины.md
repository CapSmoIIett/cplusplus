# Корутины в C++

**Корутины (coroutines)** — это механизм языка C++ (начиная с [[C++20]]), позволяющий приостанавливать и возобновлять выполнение функции, сохраняя её состояние. Корутины упрощают написание асинхронного и ленивого кода.

---

## Основная идея
- Корутина — это функция, которая может быть приостановлена (suspend) и позже возобновлена (resume), продолжая выполнение с того же места.
- Позволяет реализовывать асинхронные операции, генераторы, ленивые вычисления и др.

## Устройство корутины
- Корутина компилируется в state machine (машину состояний), которая хранит локальные переменные, позицию выполнения и служебные структуры.
- При каждом вызове `co_await`, `co_yield` или `co_return` выполнение может быть приостановлено, а состояние сохранено.
- Корутина управляется через специальный дескриптор — `std::coroutine_handle`, который позволяет вручную возобновлять, завершать и уничтожать корутину.
- Вся логика взаимодействия с внешним миром реализуется через promise_type и awaitable-объекты.

### Основные компоненты
- **promise_type** — определяет, как создаётся, приостанавливается, возобновляется и завершается корутина. Управляет возвратом значений, обработкой ошибок и взаимодействием с awaitable.
- **awaitable** — объект, поддерживающий оператор `co_await`. Определяет, когда и как корутина приостанавливается и возобновляется.
- **coroutine_handle** — дескриптор, управляющий жизненным циклом корутины (resume, destroy, done).

### Жизненный цикл корутины
1. Вызов корутинной функции создаёт promise_type и coroutine_handle.
2. Выполняется `initial_suspend` (может сразу приостановить выполнение).
3. Корутина выполняется до первого `co_await`/`co_yield`/`co_return`.
4. При каждом suspend управление возвращается вызывающему коду, состояние сохраняется.
5. Корутина может быть возобновлена через coroutine_handle или автоматически (например, по завершении асинхронной операции).
6. После завершения вызывается `final_suspend`, затем корутина уничтожается.

---

## Ключевые слова
- `co_await` — приостановить выполнение до завершения awaitable-объекта.
- `co_yield` — вернуть значение и приостановить выполнение (генераторы).
- `co_return` — завершить выполнение корутины и вернуть значение.

## Пример: простейший генератор
```cpp
#include <coroutine>
#include <iostream>
#include <optional>

struct Generator {
    struct promise_type {
        int current_value;
        std::suspend_always yield_value(int value) {
            current_value = value;
            return {};
        }
        Generator get_return_object() { return Generator{this}; }
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        void return_void() {}
        void unhandled_exception() { std::terminate(); }
    };
    promise_type* p;
    explicit Generator(promise_type* p) : p(p) {}
    int value() const { return p->current_value; }
};

Generator counter() {
    for (int i = 0; i < 3; ++i)
        co_yield i;
}

int main() {
    auto gen = counter();
    // Для полноценного генератора нужен интерфейс next(), done() и т.д.
    // В C++23 есть std::generator с удобным интерфейсом.
}
```

## Асинхронные корутины
- Позволяют писать асинхронный код в стиле "сверху вниз", без вложенных колбэков.
- Используются с awaitable-объектами (например, Boost.Asio, std::future, пользовательские типы).
- Корутина может ожидать завершения асинхронной операции с помощью `co_await`.

## Пример: асинхронная функция с co_await
```cpp
#include <coroutine>
#include <future>
#include <iostream>

std::future<int> async_add(int a, int b) {
    co_return a + b;
}

int main() {
    auto fut = async_add(2, 3);
    std::cout << fut.get() << std::endl; // 5
}
```

## Использование корутин
- Для генераторов: удобно реализовывать ленивые последовательности, итераторы, обработку потоков данных.
- Для асинхронных операций: сетевые запросы, таймеры, файловый ввод-вывод, параллельные вычисления.
- В современных библиотеках (Boost.Asio, cppcoro, Qt) корутины позволяют писать асинхронный код без вложенных колбэков и state machine.

## Архитектура корутин
- **promise_type** — класс, управляющий состоянием корутины (обработка возврата, ошибок, suspension/resume).
- **awaitable** — объект, поддерживающий оператор co_await (определяет, когда и как корутина приостанавливается и возобновляется).
- **handle** — дескриптор корутины (std::coroutine_handle), позволяет вручную управлять жизненным циклом.

## Преимущества
- Упрощают асинхронное программирование и генераторы.
- Позволяют писать "плоский" код без вложенных колбэков и state machine.
- Эффективны по памяти (не требуют отдельного стека).
- Позволяют реализовывать сложные сценарии управления потоком выполнения.

## Ограничения и замечания
- Требуют поддержки компилятора (C++20 и выше).
- Стандартная библиотека пока содержит ограниченное число готовых awaitable-типов (std::generator — с C++23, std::future, сторонние библиотеки).
- Реализация пользовательских корутин требует знания promise_type и awaitable.
- Для полноценного использования генераторов и асинхронных корутин рекомендуется использовать сторонние библиотеки (cppcoro, Boost.Asio, std::generator).

## Важно
- Корутины — мощный инструмент для асинхронного и ленивого программирования в современном C++.
- Широко используются в Boost.Asio, cppcoro, Qt, игровых движках и др.
- Грамотное проектирование promise_type и awaitable позволяет создавать эффективные и удобные абстракции для работы с корутинами.
